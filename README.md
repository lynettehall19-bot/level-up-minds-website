# Level Up Minds Website

Bright, modern multi-page educational e-commerce website prototype for Level Up Minds.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Pages

- Home: `index.html`
- Shop/Resources: `shop.html`
- About: `about.html`
- Contact: `contact.html`
- Blog/Tips: `blog.html`

## Brand assets (official uploads)

Place your official files in these locations to power the live design:

- `assets/brand/level-up-minds-logo.png` (header + hero logo)
- `assets/brand/brand-icons-sheet.png` (lightning/arrows/bursts icon sheet)
- `assets/products/grade-6-english-comprehension-pack.png`
- `assets/products/creative-writing-boost-kit.png`
- `assets/products/teacher-toolkit-term-planner.png`
- `assets/products/grade-5-writing-warmups.png`
- `assets/products/grade-7-reading-assessment-bundle.png`
- `assets/products/vocabulary-boost-pack.png`
- `assets/products/student-study-planner-kit.png`
- `assets/products/grammar-checkpoint-tests.png`

The UI will automatically fall back to existing placeholder imagery if any official file is missing.

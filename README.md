# Level Up Minds Website

Bright, modern multi-page educational e-commerce website prototype for Level Up Minds.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Pages

- Home: `index.html`
- Shop/Resources: `shop.html`
- About: `about.html`
- Contact: `contact.html`
- Blog/Tips: `blog.html`

## Notes

- Payhip links are wired as placeholders to `https://payhip.com`.
- Newsletter and contact forms are UI-only placeholders for integration.
